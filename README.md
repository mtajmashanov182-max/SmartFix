# Smartfix — сайт прошивки и ремонта телефонов

Статический сайт на чистом HTML/CSS/JS. Ничего собирать и устанавливать не надо.

## Как открыть

Двойной клик по `index.html` — откроется в браузере. Все страницы связаны между собой ссылками, работает и с диска, и с хостинга.

## Структура

```
phone-master/
├── index.html      — главная
├── services.html   — услуги (подробно по каждой)
├── ios.html        — программы для iPhone (каталог со скачиванием)
├── prices.html     — цены и условия
├── how.html        — как я работаю
├── faq.html        — частые вопросы
├── contacts.html   — контакты и адрес
├── booking.html    — запись на ремонт (форма)
├── css/style.css   — все стили, общие для страниц
├── js/anim.js      — плавное появление страницы (подключается в <head>)
├── js/main.js      — шапка, меню, формы, плавный переход по ссылкам
├── fonts/          — шрифт Montserrat (лежит локально, интернет не нужен)
├── img/bg.jpg      — фоновая фотография мастерской
└── files/          — сюда кладутся .ipa файлы для страницы ios.html
```

## Программы для iPhone (ios.html)

Кнопки «Скачать» на этой странице ведут в папку `files/`. Пока файлов там нет,
кнопки будут выдавать ошибку — это нормально, код менять не нужно, достаточно
положить файлы с правильными именами:

```
whatsapp-26.31.74.ipa      happ-plus-4.13.0.ipa
wa-business-26.31.74.ipa   advance-1.2.ipa
max-26.17.3.ipa            online-17.6.1.ipa
minecraft-1.26.33.ipa      toast-2.0.1.ipa
roblox-2.730.790.ipa
```

Имена обязательно должны быть такими — именно они прописаны в ссылках на
странице. С пробелами и русскими буквами ссылки работают через раз, поэтому
файлы надо переименовать.

Два файла — `online-17.6.1.ipa` и `toast-2.0.1.ipa` — внутри содержат другие
приложения (FamilyBudget.app и Toastmaster.app). На странице у них стоит
предупреждение; перед публикацией их стоит проверить.

Шапка и подвал продублированы в каждом файле — так сайт работает без сборщика. Если меняешь телефон или название, меняй во всех семи файлах (или скажи мне, поменяю сразу везде).

## Как сделать, чтобы форма отправляла заявки

Сейчас форма — заглушка: проверяет, что имя и телефон заполнены, показывает «Заявка принята» и ничего никуда не отправляет. Чтобы заявки приходили тебе, нужен один из вариантов.

**Вариант 1 — Formspree (проще всего, без своего сервера)**

1. Зарегистрируйся на formspree.io, создай форму, получи ссылку вида `https://formspree.io/f/xxxxxxxx`.
2. В `booking.html` замени тег формы:

```html
<form class="js-form" id="booking-form" action="https://formspree.io/f/xxxxxxxx" method="POST">
```

3. В `js/main.js` убери `e.preventDefault()` и блок с `form.reset()`. Заявки будут приходить на почту.

**Вариант 2 — Telegram-бот**

Нужен маленький сервер (Cloudflare Workers, любой хостинг с PHP или Node), который принимает данные формы и отправляет их в Telegram. Токен бота **нельзя** держать в `main.js` — его увидят все, кто откроет исходник страницы. Поэтому только через сервер.

**Вариант 3 — оставить как есть**

Форма показывает «Заявка принята», а клиент всё равно звонит или пишет в WhatsApp. Для визитки этого достаточно.

## Как выложить в интернет

- **GitHub Pages** — залей папку в репозиторий, в настройках включи Pages. Бесплатно, но адрес будет вида `твой-ник.github.io/phone-master`.
- **Netlify / Cloudflare Pages** — перетащи папку в их окно загрузки, получишь сайт и свой адрес бесплатно.
- **Свой домен** — покупаешь домен, привязываешь к хостингу, туда же кладёшь файлы.

## Проверено

Открывается локально, страницы связаны, меню сворачивается на телефоне, активный раздел подсвечивается. Формы ничего не отправляют — это заглушка до подключения одного из вариантов выше.
